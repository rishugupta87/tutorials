1. The Basics

Dictionaries are Python's hash tables - key-value pairs for fast lookups.

Creating Dictionaries

Python# Empty dictionary empty = {} empty = dict() # With initial values person = { 'name': 'Alice', 'age': 30, 'city': 'NYC' } # Using dict() constructor person = dict(name='Alice', age=30, city='NYC') # From two lists keys = ['name', 'age', 'city'] values = ['Bob', 25, 'LA'] person = dict(zip(keys, values)) # Dictionary comprehension squares = {x: x**2 for x in range(5)} # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
Key Rule: Keys must be immutable (strings, numbers, tuples). Values can be anything!

2. Accessing Values

Using [ ] brackets

Pythonperson = {'name': 'Alice', 'age': 30} # Access name = person['name'] # 'Alice' # Raises KeyError if missing city = person['city'] # ❌ KeyError!

Using .get()

Pythonperson = {'name': 'Alice', 'age': 30} # Safe access name = person.get('name') # 'Alice' # Returns None if missing city = person.get('city') # None # With default city = person.get('city', 'Unknown') # 'Unknown'
Best Practice: Use .get() when a key might not exist!

3. Adding & Modifying

Pythonperson = {'name': 'Alice'} # Add new key-value person['age'] = 30 person['city'] = 'NYC' # Modify existing person['age'] = 31 # Add if doesn't exist (safer) person.setdefault('country', 'USA') # Adds 'USA' person.setdefault('country', 'UK') # Does nothing, already exists # Update multiple at once person.update({'job': 'Engineer', 'salary': 100000}) person.update(job='Engineer', salary=100000) # Same thing # Merge dictionaries (Python 3.9+) defaults = {'theme': 'dark', 'lang': 'en'} settings = {'lang': 'es', 'size': 'large'} merged = defaults | settings # {'theme': 'dark', 'lang': 'es', 'size': 'large'}

4. Removing Items

Pythonperson = {'name': 'Alice', 'age': 30, 'city': 'NYC'} # Delete by key del person['city'] # Pop (remove and return value) age = person.pop('age') # Returns 30, removes it job = person.pop('job', None) # Returns None if missing (safe) # Remove and return arbitrary item (Python 3.7+ = last inserted) item = person.popitem() # ('name', 'Alice') # Clear all items person.clear() # {}

5. Iterating Through Dictionaries

Pythonperson = {'name': 'Alice', 'age': 30, 'city': 'NYC'} # Iterate over keys (default) for key in person: print(key) # 'name', 'age', 'city' # Iterate over keys (explicit) for key in person.keys(): print(key) # Iterate over values for value in person.values(): print(value) # 'Alice', 30, 'NYC' # Iterate over both (MOST COMMON) for key, value in person.items(): print(f"{key}: {value}") # name: Alice # age: 30 # city: NYC
Pro Tip: As of Python 3.7+, dictionaries maintain insertion order!

6. Checking Membership

Pythonperson = {'name': 'Alice', 'age': 30} # Check if key exists if 'name' in person: print("Name exists!") if 'city' not in person: print("No city!") # Check value (slower - loops through all values) if 'Alice' in person.values(): print("Alice is a value") # Get with existence check if 'age' in person: age = person['age'] # Or simpler: age = person.get('age') # Returns None if missing

7. Essential Methods Cheat Sheet

Method What It Does Example
.get(key, default) Safe access with default d.get('x', 0)
.setdefault(key, default) Get or set if missing d.setdefault('count', 0)
.update(other) Merge another dict d.update({'x': 1})
.pop(key, default) Remove and return val = d.pop('x', None)

8. Common Patterns

Counting Occurrences

Manualword_count = {} for word in words: if word in word_count: word_count[word] += 1 else: word_count[word] = 1
Betterword_count = {} for word in words: word_count[word] = word_count.get(word, 0) + 1
Even Better: Use Counter from collections!
Bestfrom collections import Counter word_count = Counter(words) word_count.most_common(3) # Top 3 most common

Grouping Items

Pythonfrom collections import defaultdict # Group people by age people = [ {'name': 'Alice', 'age': 30}, {'name': 'Bob', 'age': 25}, {'name': 'Charlie', 'age': 30} ] by_age = defaultdict(list) for person in people: by_age[person['age']].append(person['name']) # {30: ['Alice', 'Charlie'], 25: ['Bob']}

Inverting a Dictionary

Pythonoriginal = {'a': 1, 'b': 2, 'c': 3} # Swap keys and values inverted = {v: k for k, v in original.items()} # {1: 'a', 2: 'b', 3: 'c'}

Filtering a Dictionary

Pythonscores = {'Alice': 85, 'Bob': 92, 'Charlie': 78} # Keep only scores >= 80 passing = {k: v for k, v in scores.items() if v >= 80} # {'Alice': 85, 'Bob': 92}

Default Values Pattern

Python# Instead of checking existence if 'count' not in stats: stats['count'] = 0 stats['count'] += 1 # Use setdefault stats.setdefault('count', 0) stats['count'] += 1

9. Dictionary Comprehensions

Dictionary comprehensions are a powerful way to create dictionaries in a single line.

Basic Syntax

Python# Syntax: {key_expression: value_expression for item in iterable} # Create squares dictionary squares = {x: x**2 for x in range(6)} # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25} # From a list fruits = ['apple', 'banana', 'cherry'] fruit_lengths = {fruit: len(fruit) for fruit in fruits} # {'apple': 5, 'banana': 6, 'cherry': 6}

With Conditions (Filtering)

Python# Only even numbers evens = {x: x**2 for x in range(10) if x % 2 == 0} # {0: 0, 2: 4, 4: 16, 6: 36, 8: 64} # Filter dictionary by value scores = {'Alice': 85, 'Bob': 92, 'Charlie': 78, 'Diana': 95} high_scores = {name: score for name, score in scores.items() if score >= 90} # {'Bob': 92, 'Diana': 95} # Filter by key starts_with_a = {k: v for k, v in scores.items() if k.startswith('A')} # {'Alice': 85}

Transform Keys or Values

Python# Uppercase all keys original = {'name': 'Alice', 'age': 30} upper_keys = {k.upper(): v for k, v in original.items()} # {'NAME': 'Alice', 'AGE': 30} # Double all values numbers = {'a': 1, 'b': 2, 'c': 3} doubled = {k: v * 2 for k, v in numbers.items()} # {'a': 2, 'b': 4, 'c': 6} # Transform both prices = {'apple': 1.5, 'banana': 0.8} formatted = {k.upper(): f"${v:.2f}" for k, v in prices.items()} # {'APPLE': '$1.50', 'BANANA': '$0.80'}

From Two Lists (zip)

Pythonnames = ['Alice', 'Bob', 'Charlie'] ages = [30, 25, 35] # Create dictionary from two lists people = {name: age for name, age in zip(names, ages)} # {'Alice': 30, 'Bob': 25, 'Charlie': 35} # With index indexed = {i: name for i, name in enumerate(names)} # {0: 'Alice', 1: 'Bob', 2: 'Charlie'}

Nested Comprehensions

Python# Create nested dictionary matrix = {i: {j: i*j for j in range(3)} for i in range(3)} # {0: {0: 0, 1: 0, 2: 0}, # 1: {0: 0, 1: 1, 2: 2}, # 2: {0: 0, 1: 2, 2: 4}} # Flatten nested dict nested = {'a': {'x': 1, 'y': 2}, 'b': {'x': 3, 'y': 4}} flattened = {f"{k}_{sub_k}": v for k, sub_dict in nested.items() for sub_k, v in sub_dict.items()} # {'a_x': 1, 'a_y': 2, 'b_x': 3, 'b_y': 4}

Swap Keys and Values

Pythonoriginal = {'a': 1, 'b': 2, 'c': 3} # Invert dictionary inverted = {v: k for k, v in original.items()} # {1: 'a', 2: 'b', 3: 'c'} # Warning: If values aren't unique, last one wins! dups = {'a': 1, 'b': 1, 'c': 2} inverted = {v: k for k, v in dups.items()} # {1: 'b', 2: 'c'} # 'a' was overwritten by 'b'

Conditional Values

Python# Different value based on condition numbers = range(1, 6) parity = {x: 'even' if x % 2 == 0 else 'odd' for x in numbers} # {1: 'odd', 2: 'even', 3: 'odd', 4: 'even', 5: 'odd'} # Grade assignment scores = {'Alice': 85, 'Bob': 92, 'Charlie': 78} grades = {name: 'A' if score >= 90 else 'B' if score >= 80 else 'C' for name, score in scores.items()} # {'Alice': 'B', 'Bob': 'A', 'Charlie': 'C'}

Real-World Examples

Python# Count character frequency text = "hello world" char_count = {char: text.count(char) for char in set(text)} # Create lookup table products = [ {'id': 1, 'name': 'Apple', 'price': 1.5}, {'id': 2, 'name': 'Banana', 'price': 0.8} ] product_lookup = {p['id']: p for p in products} # {1: {'id': 1, 'name': 'Apple', 'price': 1.5}, ...} # Parse query string query = "name=Alice&age=30&city=NYC" params = {k: v for k, v in (pair.split('=') for pair in query.split('&'))} # {'name': 'Alice', 'age': '30', 'city': 'NYC'}
When to Use: Dictionary comprehensions are great for transforming or filtering existing data. If your logic gets too complex, use a regular loop for readability!

10. Nested Dictionaries

Python# Dictionary of dictionaries users = { 'alice': { 'age': 30, 'email': '[email protected]', 'active': True }, 'bob': { 'age': 25, 'email': '[email protected]', 'active': False } } # Accessing nested values alice_age = users['alice']['age'] # 30 # Safe nested access bob_phone = users.get('bob', {}).get('phone', 'N/A') # 'N/A' # Iterating nested dicts for username, info in users.items(): print(f"{username}: {info['email']}")

12. Common Mistakes to Avoid

❌ Using Mutable Keys

Wrongmy_dict = {[1, 2]: 'value'} # ❌ Lists can't be keys! my_dict = {{1: 2}: 'value'} # ❌ Dicts can't be keys!
Correctmy_dict = {(1, 2): 'value'} # ✅ Tuples work! my_dict = {'1,2': 'value'} # ✅ Strings work!

❌ Modifying During Iteration

Wrongfor key in my_dict: if condition: del my_dict[key] # ❌ RuntimeError!
Correct# Iterate over a copy for key in list(my_dict.keys()): if condition: del my_dict[key] # Or use dict comprehension my_dict = {k: v for k, v in my_dict.items() if not condition}

❌ Expecting KeyError to Be Silent

Wrongvalue = my_dict['missing_key'] # ❌ Crashes!
Correctvalue = my_dict.get('missing_key') # ✅ Returns None value = my_dict.get('missing_key', 'default') # ✅ Returns 'default'

Key Takeaways

Remember These:
  • Use .get() for safe access when keys might not exist
  • Use .items() to iterate through both keys and values
  • Dictionary comprehensions are powerful and fast
  • Keys must be immutable (strings, numbers, tuples)
  • Since Python 3.7+, dicts preserve insertion order
  • Use defaultdict or Counter from collections for advanced patterns
